## Prisma versions

- **Prisma 7.1 and later** are supported, and tested on the oldest and the newest in CI.
- **Prisma 6** is not: it has no SQL comments, and its query engine runs the driver adapter outside
  the request's async context, so statements cannot be tied to their request.
- **Prisma 8** needs its own integration, built on its new middleware, once it is stable.

## Node servers

The [preload](/docs/guides/node) works with any framework that serves through Node's `http` module.
CI runs the same requests, with Prisma against PostgreSQL, in each of these:

- **Express 4.18 and later**, 5 included, tested on 4.18.0, 5.0.0 and the newest. Before 4.18,
  Express's body parser drops the request's async context: a route that reads a body loses its
  queries.
- **Fastify**, tested on 4.26.0, 5.0.0 and the newest.
- **Koa 3**, **Hapi 21**, **NestJS 12** on Express, and **Hono 4** on `@hono/node-server`.

## Node

Node 22.15 or later, tested on 22.15, 22 and 24. Node 20 is not supported: it lacks the synchronous
module hooks the preload uses, and its support ended in April 2026.
